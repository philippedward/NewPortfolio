# Portfolio v1

Portfolio personnel fait avec Eleventy, Sass et JavaScript.
Présente mes projets, dessins, réalisations graphiques, vidéos, CV et éléments de design.

## Stack

Eleventy, Nunjucks, Sass, JavaScript, Decap CMS, GSAP

## Installation

```bash
npm install
npm run dev
```

Le site tourne sur `http://localhost:8080`

## Build

```bash
npm run build
```

Le site final est dans `_site/`.

## Structure

- `src/_data/` → contenu (projets, dessins, config)
- `src/views/` → templates Nunjucks
- `src/assets/` → JS et Sass
- `src/public/` → fonts, images, vidéos
